# Hi, I'm Daniel.

I build software that helps engineering teams ship with less friction and more confidence.

For the past decade that has mostly meant backend systems, developer tooling, Kubernetes, cloud platforms, and secure delivery. The common thread has never really been infrastructure—it has been reducing cycle time by replacing recurring engineering pain with boring, repeatable software.

## Currently building

### Seevee

An agent-driven resume workbench that treats a career as a conversation instead of a document.

### Timerbox

A cross-platform desktop timer in Go/Gio inspired by the workflow I've depended on for years.

## Things I seem to believe

- Production is the last mile.
- Build studies in miniature before arguing about architecture.
- Fast feedback loops beat heroic effort.
- Make the wrong thing hard and the right thing possible (and maybe even fun).
- The computer is an outboard brain. Refactor it accordingly.
